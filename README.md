# PMKnowledgeBase

产品经理技能与知识学习仓库，围绕知识、技能、案例、资料、实操、工具、行业与趋势建立完整的产品管理知识体系。

**Learn → Think → Practice → Build → Review → Grow**

从基础知识到方法论，从案例分析到实际项目，从工具使用到行业趋势，持续沉淀产品经理的专业能力、商业思维、用户洞察、技术理解、数据分析、产品设计与执行能力。

> Knowledge is the foundation.  
> Practice turns knowledge into capability.

## 知识体系结构

| 目录 | 定位 |
|------|------|
| [知识](./知识/) | 产品管理基础概念、理论与框架 |
| [技能](./技能/) | 可训练、可迁移的产品能力项 |
| [案例](./案例/) | 产品与商业案例分析 |
| [资料](./资料/) | 书籍、文章、课程与参考材料 |
| [实操](./实操/) | 练习、作业与真实项目实践 |
| [工具](./工具/) | 产品工作中的常用工具与用法 |
| [行业与趋势](./行业与趋势/) | 行业动态、赛道洞察与趋势观察 |
